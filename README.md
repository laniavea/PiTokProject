# PiTok
<br>

PiTok представляет из себя токен типа IERC-20, который используется совместно с вложенным смарт-контрактом. Поскольку никто из нашей группы не имел опыта разработки WEB-3 инструментов, то данная тема была выбрана во многом, как учебная.

Наш смарт контракт реализует покупку и владение участков из первого миллиона цифр после запятой числа Пи с использованием собственного токена. Данный проект, несмотря на свою несерьезность, позволил нам обучиться основам создания смарт-контрактов, их интеграции друг с другом и внешними системами. Также мы хотели попробовать сделать эффективную, с точки зрения вычислительных ресурсов, систему, которая могла бы проверять и покупать желанные последовательности без необходимости траты большого числа газа.

<br>

## Порядок установки (ganache/truffle)
1) Склонировать проект
2) Создать venv, активировать виртуальную среду и установить пакет web3 (pip install web3)
3) Открыть Ganache и создать eth сеть
4) Выполнить truffle migrate, *тестировалось на версии компилятора 0.8.17*
5) Опц. В ganache добавить проект, выбрав файл настроек truffle
6) Сминтить токены на аккаунт в сети, выполнив ```./scripts/mint_pi.py```
7) Запустить интерактивное приложение для работы со смарт контрактом ```./scripts/check_pi.py```
8) Воспользоваться покупкой / проверкой последовательности
